MAP 测试备考指南

它不是一场可以突击的考试，但绝对是一场可以准备的考试。

Betty & Jerry · 吉祥书院 MAP 备考 2026 年 3 月

如果你的孩子正在申请东京的国际学校，或者已经在国际学校就读，你大概率会遇到一个名字——MAP。

MAP 测试是东京很多国际学校用于入学评估和学业追踪的标准化考试。ASIJ、KIST、St. Mary's、品川国际、Saint Maur、横滨国际等学校都在使用它。对于准备入学考试的家庭来说，理解 MAP 是什么、怎么考、怎么准备，是一个绑不开的话题。

我们自己的孩子参加过 MAP 测试，在陪伴其他家庭备考的过程中也积累了不少经验。这篇文章把我们了解的一切整理出来，希望帮你和孩子更从容地面对这场考试。

"MAP 不是一场可以突击的考试，但绝对是一场可以准备的考试。关键在于：准备的方向对不对。"

MAP 测试是什么

MAP Growth（Measures of Academic Progress）是由美国非营利教育研究机构 NWEA 开发的标准化测试，目前在全球 145 个国家的 9500 多所学校使用，评分基于超过 1.38 亿次测试数据。

MAP 最大的特点是自适应（Computer Adaptive Testing）：每一道题的难度会根据前一题的作答情况实时调整。答对了，下一题更难；答错了，下一题更简单。测试结束时，系统会精确定位孩子的学术水平——设计目标是让每个学生答对约 50% 的题目。

这意味着：做到一半的题不会做，是完全正常的。这不是孩子不行，而是测试在寻找他的能力边界。很多第一次参加 MAP 的家庭不了解这一点，孩子出来后说"好多题不会"，家长就慌了。其实这恰恰说明测试在按预期工作。

MAP 的目标不是让孩子答对每一题，而是找到真实的能力边界 — 做到一半不会了，恰恰说明测试在按预期工作

三个考试科目

MAP 通常考三个科目，每科约 40-53 道题，每科约 45-60 分钟：

Reading（阅读）——考查阅读理解能力，包括文学类文本（故事、诗歌）和信息类文本（科学文章、说明文、传记等）。题目涉及主旨概括、细节推断、作者意图分析、词汇理解等。

Language Usage（语言运用）——考查英语语法、拼写、标点、句子结构和写作技巧。包括主谓一致、时态、标点符号使用、段落组织等。

Mathematics（数学）——考查数感与运算、代数思维、几何、测量、数据与统计。题目以选择题和填空为主，但注意：很多数学题是英文应用题，需要先读懂题意再计算。

一个需要特别了解的机制

MAP 测试中，提交了答案就不能返回修改。这和很多传统考试不同——没有"先做简单的再回头做难的"这个策略。每一道题都需要在当下认真作答。

RIT 分数怎么理解

MAP 的成绩不是百分制，也不是 A/B/C 等级，而是用 RIT 分数（Rasch Unit） 来表示。这是一个连续的能力量表，范围大约在 100-300 之间。

RIT 分数的核心特点是：不绑定年级。如果一个 4 年级的孩子和一个 8 年级的孩子在阅读上都考了 210 分，那么他们的阅读能力处于同一水平。这也意味着，RIT 分数可以非常精确地衡量一个孩子在某一学科上"处于几年级的水平"。

分数怎么看

  • 50th percentile（第 50 百分位）= 美国同年级学生的平均水平
  • 75th percentile = 中上水平
  • 90th percentile 及以上 = 优秀，进入顶尖学校的竞争区间

需要注意的是：东京国际学校的学生平均水平通常在美国标准的第 60-70 百分位。也就是说，如果你的孩子考了美国第 50 百分位，在东京的国际学校里实际上可能低于同学的平均水平。申请顶尖学校（如 ASIJ），数学建议达到 90th percentile 以上。

另外，RIT 分数每次测试的正常波动范围在 ±3 分以内。如果两次考试相差不超过 3 分，不需要过度解读——这属于测量误差。

怎么准备 MAP

先回答一个家长最关心的问题：MAP 能不能临时抱佛脚？

很难。MAP 的题库非常庞大，每个学生看到的题目都不同，而且是自适应的。靠背题、刷题来"押中"考试内容，基本不可能。

但这不意味着无法准备。MAP 考查的是真实的学术能力——阅读理解、语言运用和数学。这些能力是可以系统提升的，关键是准备方向和方法要对。

MAP 备考的核心不是背题，而是系统提升真实能力 — 方向对了，进步会在测试结果里清晰呈现

一、熟悉考试形式

第一次参加 MAP 的孩子，最常见的问题不是"不会做"，而是"不知道怎么做"——不适应自适应模式、不知道不能返回修改、遇到难题就慌。

具体怎么做：

  • 我们有专门研发的 MAP 测试和对应的练习提分软件，让孩子体验考试界面和操作方式，获得评测结果，且可以实时跟踪学习能力的变化，调整匹配的练习难度，保持和 MAP 一样的逻辑
  • 告诉孩子：题目越做越难是正常的、好的信号——说明前面答对了很多
  • 提醒孩子：每一题认真作答，提交后不能修改

二、阅读——最需要长期积累的科目

阅读是大多数华人孩子 MAP 成绩中最薄弱的部分，也是最难短期突破的。MAP 阅读部分的词汇量要求远超中国体制内的英语教学水平——G3-G5 的 MAP 阅读词汇量已经超过中国高考英语的要求。

具体怎么做：

  • 每天至少 10 分钟英文阅读，类型要多样——不能只看故事书，还要读科学文章、新闻报道、传记等非虚构类文本（informational text）
  • MAP 测试报告会给出一个 Lexile 阅读级别，可以用它来匹配适合难度的读物
  • 推荐使用 Newsela（可调节难度的新闻文章）和 CommonLit（免费阅读理解练习）
  • 读完之后和孩子讨论：这篇文章讲了什么？作者想说明什么？你从哪里推断出来的？——这些就是 MAP 阅读在考的东西

三、数学——发挥优势，注意术语

数学通常是华人孩子的强项。中国数学教育的基础训练比美国体系扎实得多，大部分孩子在数学上的 RIT 分数会明显高于阅读和语言。

但有一个容易被忽略的问题：很多数学题是英文应用题。孩子可能完全会做这道题，但因为看不懂题目的英文描述而做错。

具体怎么做：

  • 整理一份英文数学术语表：quotient（商）、remainder（余数）、numerator/denominator（分子/分母）、perpendicular（垂直）、isosceles（等腰）等
  • 用美国体系的英文数学教材做练习，而不是只用中文数学书
  • 做完计算后检查一遍——MAP 数学的丢分往往不是不会，而是粗心

四、语言运用——系统学语法

Language Usage 考的是英语语法、标点和写作规范。对母语为中文的孩子来说，这部分需要系统学习：

  • 主谓一致、动词时态、代词用法、形容词/副词区分
  • 标点符号规则（逗号、分号、引号在对话中的用法）
  • 句子结构（完整句 vs 碎片句、修饰语位置）
  • 段落组织（主题句、过渡句、论点支撑）

一个有效的方法：让孩子坚持写英文日记。不需要长，每天 3-5 句话就够。写的过程中自然会遇到语法和标点问题，这比单纯做语法练习题更有效。

"数学考的是能力，阅读考的是积累。语言运用介于两者之间——有规律可循，但需要在实际使用中巩固。"

华人孩子的常见挑战

在我们陪伴过的家庭中，华人孩子参加 MAP 测试时有几个反复出现的问题：

阅读是最大的瓶颈

MAP 的阅读部分不只是考"能不能读懂"，还考推断、分析和批判性思维。而且从 G3-G4 开始，信息类文本（科学文章、历史文档等）的比重明显增加。很多在日常生活中英语沟通没问题的孩子，在面对学术性阅读材料时会明显吃力。

核心策略：大量阅读非虚构类英文材料，而不是只看英文故事书。科学类文章、新闻报道、百科词条——这些才是 MAP 阅读的主战场。

数学"会做不会读"

华人孩子的计算能力通常很强，但 MAP 数学中的应用题是用英文出题的。"quotient""remainder""perpendicular"这些词，孩子可能从来没见过英文版本。

核心策略：做一份中英对照的数学术语表，日常练习用英文数学教材。

第一次考试的"不适应减分"

这是我们在品川国际学校访校文章中也提到过的：第一次参加 MAP 的孩子，成绩往往不能反映真实水平。原因不是题目难，而是对自适应模式的陌生感——题目越做越难导致心理压力，不能返回修改导致犹豫不决，计时感模糊导致节奏失控。

核心策略：考前至少做 1-2 次模拟练习，让孩子熟悉"题目会越来越难"这件事。

熟悉考试节奏是备考的第一步 — 模拟练习让孩子在正式考试前，就已经知道会发生什么

用数学拉分是可行的策略

如果阅读和语言短期内难以大幅提升，把数学考到 90th percentile 以上是一个非常务实的策略。对于重视 STEM 的学校（如 ASIJ），数学成绩的权重很高。华人孩子在数学上的优势是真实的——关键是确保不被英文题意绊倒。

给家长的实用建议

考试当天

  • 确保孩子睡眠充足、吃好早餐。MAP 每科 45-60 分钟，需要持续的注意力
  • 提前告诉孩子：题目会越做越难，这是正常的；做对一半左右是设计如此，不要慌
  • MAP 测试不限时，不需要赶时间，但也不要在一道题上纠结太久——如果实在不确定，选一个最合理的答案提交，然后集中精力做下一题

拿到成绩后

  • 看 RIT 分数了解绝对水平，看百分位了解相对位置
  • 报告中的 Lexile 阅读级别可以用来给孩子选择合适难度的英文读物
  • 如果学校每学期都考 MAP，关注增长趋势比关注单次分数更重要——每学期进步 2-8 个 RIT 分数是正常的
  • 单次分数波动 ±3 分属于正常误差，不需要过度解读

写在最后

MAP 测试对很多华人家庭来说是一个全新的概念。它和中国体制内的考试逻辑完全不同——没有固定的考试范围，没有标准答案可以背诵，每个孩子的试卷都不一样。

但换一个角度看，这也意味着：MAP 测试不会因为一次发挥失常就"考砸"——自适应机制会帮助它找到孩子的真实水平。而且，MAP 考查的能力——阅读理解、数学思维、语言运用——正是在国际学校学习和生活中最需要的基础能力。

准备 MAP 的过程，其实就是在帮孩子为国际学校的学习做准备。方向对了，考试成绩和学业适应会同步提升。
